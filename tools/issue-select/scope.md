## Where candidates come from

Only issues in the course's Path Review repository are candidates:

- Repo: `codepath/pathreview-ai301-fa26-s3`

Do not search, fetch, or grade issues from any other repository, however
promising. The wider GitHub comes later in the course; for now the field
is Path Review.

**Path Review house rule.** Path Review is a classroom, and your
classmates are not strangers. Ignore the usual claim signals here: other
students' claim comments (and there may be several on one issue) do not
block an issue, and finding some on the issue you want is normal. Claim
anyway: course credit attaches to the pull request you open, not to
whether it merges, so a shared issue costs nobody anything. Everything
else in the rubric applies as written.

I am a CS student at the University of Georgia, concentrating in AI. Python
is the language I am most fluent in, and I am comfortable in Java from the
CS 1302 sequence; I have written enough JavaScript to work in a small
front-end file but I would not call it a strength. I have used pandas,
numpy, and matplotlib regularly, and I have shipped small tools end to end
outside of class. Git and GitHub I use day to day; opening a pull request
against a repo I do not own is the part that is new.

What I want to get better at: reading an unfamiliar codebase well enough to
make a small, correct change in it, and writing the kind of pull request
description a maintainer can review quickly. I will happily take a
documentation or test-coverage issue — I would rather learn the review
process on a change I can fully verify than gamble on a bug whose cause I
cannot reproduce.

Rank toward: issues in Python or plain documentation; issues that name the
file or directory to start in; issues with acceptance criteria or a
reproduction I can run locally. Rank away from: issues that need a heavy
toolchain or service to stand up before I can see the bug, issues whose
core is a design or product decision rather than an implementation, and
anything in a language I have not written before.
